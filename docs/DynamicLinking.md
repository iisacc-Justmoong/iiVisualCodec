# 동적 라이브러리 빌드

이미지, 공간, 비전, 기하와 선택한 비디오·3D·CAD·OpenCV·USD 구성 요소는
기본적으로 각각 공유 라이브러리다. `BUILD_SHARED_LIBS=OFF`를 지정하면 정적
빌드를 선택할 수 있다. 공개 CMake 구성 요소 이름은 유지되며 Windows DLL,
iOS 프레임워크와 WebAssembly 사이드 모듈에 맞춰 설치한다. 각 대상에 필요한
외부 코덱과 런타임은 해당 플랫폼용으로 준비되어야 한다.

테스트는 구성 요소의 유형, 연결과 기존 코덱 동작을 검사한다. 테스트 프로그램의
통과는 애플리케이션이나 기기의 실행을 의미하지 않는다.

Emscripten 소비자 설정은 공유 사이드 모듈을 가져오기 전에 CMake의 공유 라이브러리 지원을 활성화한다. 앱의 메인 모듈 컴파일·링크 옵션은 빌더 또는 앱이 지정해야 한다.
